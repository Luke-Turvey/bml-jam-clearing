Let $G_t$ be an arbitrary configuration at time $t$ in an $n \times n$ grid. First create an $n \times n$ array in which each North car is represented by a $3$, each East car is represented by a $1$ and each empty space is represented by a $0$.

To obtain $G_t$ from $G_{t-1}$, use the following updates, beginning with a North update at $t=1$. For odd time steps $t$,
\begin{enumerate}
    \item Remove the bottom row of $G$, and append a row of $0$'s to the top of $G$. Call this new array $S$ (Shifted grid),
    \item $I = G - S$ (Information grid),
    \item Replace all elements of $I$ not equal to $3$ with $0$, and call this array $B$,
    \item Remove the top row of $B$, and append a row of $0$'s to the bottom of $B$. Call this array $A$.
    \item $N = G + A + B$.
    \item Replace all elements of $N$ equal to $6$ with $0$
\end{enumerate}
For even time steps $t$,
\begin{enumerate}
    \item Remove the first column of $G$, and append a column of $0$'s to the right of $G$. Call this new array $S$ (Shifted grid),
    \item $I = G - S$ (Information grid),
    \item Replace all elements of $I$ not equal to $1$ with $0$, and call this array $B$,
    \item Remove the last column of $B$, and append a row of $0$'s to the left of $B$. Call this array $A$.
    \item $N = G + A + B$.
    \item Replace all elements of $N$ equal to $2$ with $0$
\end{enumerate}
In each case the array $N$ is exactly the configuration $G_t$. \\
